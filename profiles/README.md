# profiles/

Community vendor profiles. One file per profile, path `profiles/<category>/<vendor>/<slug>.yaml`.

Empty on purpose as of 2026-09-11. The curated set that seeds every Kaleidoscope tenant lives in the platform monorepo. Profiles here extend those by slug and add vendor-specific OIDs.

Start from `../examples/_template.yaml`. Format reference: `../docs/FORMAT.md`. Rules: `../CONTRIBUTING.md`.
